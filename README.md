# FOCUS — معرض الأعمال والملف التعريفي

موقع ثابت (HTML + CSS + JS) لمؤسسة **فوكس للتسويق والإنتاج الإعلاني**، جاهز للرفع على Vercel بدون أي أوامر بناء.

| الصفحة | المسار | الوصف |
|---|---|---|
| معرض الأعمال | `/` (`index.html`) | الموقع الرئيسي — عربي/إنجليزي، فلاتر للأعمال، عارض صور |
| الملف التعريفي | `/profile` (`profile.html`) | 9 صفحات A4 أفقية جاهزة للطباعة أو الحفظ PDF |

## الرفع على Vercel

**الطريقة 1 — عبر GitHub (الأسهل للتحديث لاحقًا)**
1. ارفع محتويات هذا المجلد إلى مستودع جديد على GitHub.
2. من vercel.com اختر **Add New → Project** ثم اختر المستودع.
3. Framework Preset: **Other** — اترك Build Command و Output Directory فارغين.
4. اضغط **Deploy**.

**الطريقة 2 — عبر سطر الأوامر**
```bash
npm i -g vercel
cd focus-portfolio
vercel          # معاينة
vercel --prod   # النشر النهائي
```

بعد النشر: افتح `index.html` و `profile.html` وغيّر `content="/assets/img/og-cover.jpg"` إلى الرابط الكامل (مثل `https://focus.vercel.app/assets/img/og-cover.jpg`) لتظهر صورة المعاينة عند مشاركة الرابط.

## الملف التعريفي PDF
افتح `/profile` ثم اضغط **طباعة / حفظ PDF** واختر «حفظ بصيغة PDF». الإعدادات الصحيحة تُضبط تلقائيًا (A4 أفقي، بدون هوامش، مع الخلفيات). يفضّل Chrome أو Edge.

## التعديل

- **الألوان:** `css/style.css` و `css/profile.css` — المتغير `--lime` (حاليًا `#D3DE25` من ملف الشعار).
- **بيانات التواصل:** ابحث واستبدل في `index.html` و `profile.html`:
  `fo.c.s.creative.co@gmail.com` · `+967 777 59 2006` / `967777592006` · `fo.c.o`
- **الأعمال والخدمات والقيم:** كلها في أعلى `js/main.js` (`PROJECTS` و `WORKS` و `SERVICES` و `VALUES` و `STEPS`) بالعربي والإنجليزي.
- **إضافة عمل لعميل موجود:** ضع الصورة في `assets/img/` (يفضّل WebP بنسبة 4:5) وأضف سطرًا في `WORKS` مع `p: 'najah'` أو `p: 'canary'` أو `p: 'kabous'`.
- **إضافة عميل جديد:** أضف دراسة حالة في `PROJECTS` (الشعار، العنوان، الوصف، البيانات، الفكرة المحورية) ثم أعماله في `WORKS` بنفس المعرّف. العميل بعملين يظهر بجانب أعماله في صف واحد، وبثلاثة أعمال تظهر في ثلاثة أعمدة، وبأربعة في أربعة.
- **إضافة ريلز:** ضع الفيديو في `assets/video/` وأضف عنصرًا بـ `cat: 'reels'` و `video: 'assets/video/اسم-الملف.mp4'`. يظهر فلتر «ريلز» تلقائيًا.
- **النصوص الإنجليزية:** كائن `EN` في `js/main.js`.
- **خط ثمانية الأصلي:** ضع ملفات `woff2` في مجلد `fonts/` وفعّل كتلة `@font-face` في أعلى `css/style.css`. حتى ذلك الحين يُستخدم IBM Plex Sans Arabic (نفس خط ملف العرض).
